# サイゼ注文マスター(非公式ファンゲーム)

サイゼリヤの「番号を書いて注文する」仕組みをゲームにした、ブラウザだけで遊べる1ファイルのアプリです。`index.html` をスマホやPCのブラウザで開くだけで遊べます。

## モード
| 番号 | モード | 遊び方 |
|---|---|---|
| 0001 | 連続注文タイムアタック | 料理名を聞いて番号を書く。正解で+1.5秒、5連続ごとに+3秒ボーナス、まちがえると−5秒。 |
| 1000 | 予算ぴったりチャレンジ | 1000円・1500円・2000円のお題ちょうどになるよう番号で注文。 |
| 2101 | 番号から料理あて | 番号を見て料理を4択で当てる(10問)。 |
| 0004 | 団体さんの一括注文 | 数秒だけ見える全員分の注文を覚えて書く。成功で人数が増える。 |
| 3906 | デザートは「すぐ」か「あとで」 | 食後に出す場合の番号(3906など)まで正しく書けるか。 |
| 0320 | どっちが高い? | 2品の値段くらべで連続正解に挑戦。 |
| 3401 | 酔わせて満腹バトル | CPUと対戦。手札の料理の番号を書いて相手に届け、満腹か酔いつぶれでダウンさせる。番号ミスは自分が食べる。酔うと注文パッドの数字がばらばらに。満腹・酔いの数値は遊び用の設定。相手は大人のキャラクター12人(★1〜★5)。 |

学習モード(番号のしくみ・暗記カード・入力練習)で覚えた品は★で記録されます。番号の入力は、報道・利用者ブログで紹介されているセルフオーダーの流れ(番号入力→商品名表示→「次へ進む」→数量→「注文かごへ追加する」)を参考にした独自デザインです。ロゴや公式素材は使っていません。学習モードはテーマ別(サラダ・パスタ・デザートとドリンクなど)に暗記カード・練習・10問テストができます。

「マイカード」では、好きな料理に♡を付けたり、ゲームに入っていない料理を料理名・番号・覚え方メモで自作したりして、自分だけの暗記カード・練習・テストができます(自作カードは学習モードだけで使い、ゲームの出題には混ぜません)。

自己ベストと称号はその端末のブラウザに保存されます。結果はXにシェアできます。
