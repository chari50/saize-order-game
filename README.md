# サイゼ注文マスター(非公式ファンゲーム)

サイゼリヤの「番号を書いて注文する」仕組みをゲームにした、ブラウザだけで遊べる1ファイルのアプリです。`index.html` をスマホやPCのブラウザで開くだけで遊べます。

## モード
| 番号 | モード | 遊び方 |
|---|---|---|
| 0001 | 連続注文タイムアタック | 料理名を聞いて番号を書く。正解で+1.5秒、5連続ごとに+3秒ボーナス、まちがえると−5秒。 |
| 1000 | 予算ぴったりチャレンジ | 1000円・1500円・2000円のお題ちょうどになるよう番号で注文。 |
| 2101 | 番号から料理あて | 番号を見て料理を4択で当てる(10問)。 |
| 0004 | 団体さんの一括注文 | 数秒だけ見える全員分の注文を覚えて書く。成功で人数が増える。 |
| 3906 | デザートは「すぐ」か「あとで」 | 食後に出す場合の番号(3906など)まで正しく書けるか。 |
| 0320 | どっちが高い? | 2品の値段くらべで連続正解に挑戦。 |

自己ベストと称号はその端末のブラウザに保存されます。結果はXにシェアできます。
